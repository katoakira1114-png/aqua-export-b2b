# Aqua Export International | B2B Overseas Wholesale Portal

海外アクアリウムバイヤー向け B2B オンラインカタログ・受発注リクエスト（Proforma Request）システムです。
国内店舗向け受発注システム（Googleスプレッドシート本番データベース）と連携し、ゼロトラスト（機密隠蔽・在庫非連動・ブルートフォース防御）に基づいて構築されています。

## ⚡ クイックスタート & ローカルプレビュー

本システムは外部ビルドツール（Node.js / Webpack等）を一切必要とせず、ブラウザ単体で即座に動作します。

1. `overseas.html` または `index.html` を任意のWebブラウザでダブルクリックして開きます。
2. ゲートウェイPIN入力画面が表示されるので、初期PINコード **`9876`** を入力します。
3. 認証後、B2B卸売カタログが表示され、言語切替（英語/繁体中文/简体中文）、通貨切替（USD/JPY）、カート機能、MOVプログレスバー、CITES法的免責モーダル、および **Proforma Order PDFの即時自動ダウンロード** をテストできます。

## 🛡️ セキュリティ設計ハイライト

- **PIN平文直書きの禁止**: クライアントJS内に `9876` を直接ハードコードせず、SHA-256ハッシュ検証およびGASサーバー側検証を実施。
- **ブルートフォース防御**: 連続5回失敗時に15分間の端末ロックアウトを発動。
- **機密データの物理的除外 (BFF)**: 仕入れ値、国内卸値、仕入れ先、国内在庫数をAPIレスポンスから物理的に削除。
- **在庫非連動**: 海外からの注文は「見積リクエスト」として扱い、スプレッドシート上の在庫カウントは減算しません。
- **法的免責の必須化**: CITES（ワシントン条約）及び国際空輸運賃に関する3項目の同意なしには発注を完了できないゲートを設置。
- **完全無料枠運用**: GitHub Pages (ホスティング無料) × Google Apps Script (バックエンド無料) でサーバー代0円。

詳細なセットアップおよび本番スプレッドシートとの連携手順は **`DEPLOYMENT_AND_SECURITY.md`** をご参照ください。
